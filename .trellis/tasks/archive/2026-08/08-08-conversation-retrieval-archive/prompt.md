# Execution Prompt

以 clean-room 方式为 xi-ai-web 实现 P2A“本地会话检索与归档”。仅借鉴公开产品行为，不复制 LobeChat 或其他项目的源码、组件结构、样式、文案、资产、依赖、数据模型或应用架构。

保持当前 React/Vite/Express/IndexedDB/BYOK 架构，不引入新依赖，不改 Provider 端点，不新增服务端会话存储、账号、分享、同步、向量检索或远程搜索。搜索仅覆盖标题、预览和持久化消息正文，排除附件、知识引用、URL、API Key 和 transient 状态，并保证所有检索操作零网络请求。

增加可选 `archivedAt`，实现显式归档和恢复；归档取消置顶并移出活跃会话堆栈，但完整保留消息和分支 provenance。恢复保持未置顶、更新最近使用时间、置顶展开并折叠其他会话。父子分支状态不级联，流式期间禁止归档、恢复和切换写操作。最后一个活跃会话被归档时必须创建一个新的中性对话。

使用现有 Dialog、Lucide 图标、设计 token、焦点和单滚动容器规范实现“管理会话”，包含搜索、活跃/已归档筛选、计数、紧凑行、打开、归档和恢复。桌面控件至少 36px，移动端至少 44px，并覆盖深色模式、键盘、焦点与无溢出。

按 P0 合同、P1 持久化、P2 Chat 状态、P3 管理界面、P4 全量相关门禁顺序持续执行。禁止加入会话分组、永久删除、批量操作、AI 分类、语义搜索、云会话、分支树、Artifacts 或 MCP。
